Add Recipients for ACH Transfers

This guide explains how to add or update ACH transfer recipients so you can securely send payments to the right bank accounts.

1
Tap the menu icon
2
Tap "Business Management"
3
Tap "Recipient Management"
4
This page is where you can select "Add recipient" in the top right to add a recipient or select the three dots on the right side of a recipient to edit or remove them
5
When adding a recipient, select 'Business Recipient' for ACH Transfers
6
Select the business account to add the recipient to then hit "Next"
7
Enter in the recipient's name then select "Next"
8
Select "Add Account" to enter in the recipient's account details
9
Select ACH as the payment type
10
Enter in the name on the account, a nickname for the recipient and the account number then select the magnifying glass to enter a routing number
11
Enter in the routing number or type in the Financial Institution's name and select "Search"
12
Select the correct Financial Institution from the list
13
Select if the new recipient should be verified with prenotes
ⓘ
Verifying with pre-notes sends a $0 test entry to verify the recipient’s routing and account number before sending a payment. No funds are transferred. Choosing this option will delay the first payment by 1-2 business days while the verification is completed.
14
Select "Add recipient"
15
A message will appear when the recipient has been added successfully
